# The Shelf Is a Camera

Published: 2025-11-30
Tag: ESSAY

An isometric shelf never moves; only the camera does. Once you accept that, a lot of interface problems quietly rename themselves as cinematography problems.

Occlusion is not a bug to eliminate but a blocking decision. Which box hides which box is a question about where you put the lens, and the lens is a point of view, and a point of view is an opinion.

The same is true of a portfolio. The work does not change when you rearrange the room around it. The visitor changes.
