# Notes on Information Overload

Published: 2026-05-18
Tag: NOTES

The feed does not end; only attention does. That asymmetry is the whole problem. Any tool that pretends the stream can be finished is lying on the first screen.

Flovvas started from a different admission: the shelf is finite. A reader can hold perhaps nine open threads before the threads start reading the reader. So the tool recycles slots, fixes the camera, and lets the fog swallow whatever scrolls past the edge.

Finite assets, infinite perception. The game engines knew this decades ago. The reading tools are still catching up.
