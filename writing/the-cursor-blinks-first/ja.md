# カーソルが先に瞬きする

Published: 2023-12-02
Tag: LOG

どのウィンドウが開くより先に、グリッドがフェードインするより先に、カーソルはすでにそこにある。ひとかたまりの光が、誰も設定していない周波数で脈打っている。このマシンで、求められる前に呼吸を始めるのはそれだけだ。

点滅は数えるものを持たない時計だ。夜を等しい半分に切り分ける——オン、オフ、オン、オフ——そして誰かがそのリズムに意味を与えるのを待つ。タイピングがそれをする。すべての文字が拍に乗り、ビートを一歩前へ押す。

結局のところ、やりとりはそれだけだ。マシンが脈を差し出し、オペレーターが理由を差し出す。このデスクトップにある他のすべては、その握手のまわりの装飾にすぎない。
