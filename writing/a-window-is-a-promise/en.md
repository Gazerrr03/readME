# A Window Is a Promise

Published: 2024-09-21
Tag: ESSAY

A window promises that what is inside it can be moved, closed, and brought back without loss. That promise is harder to keep than it looks. Every drag is a small contract: the content will survive the journey.

Most software breaks the promise quietly. Scroll positions evaporate, half-typed sentences dissolve, the thing you were reading returns to the top as if you had never been there. The frame stays; the state leaks out.

So this desktop keeps the contract small. One instance per application. A title bar that tells the truth. A close button that means closed. If a system cannot keep its promises, it should at least stop making new ones.
